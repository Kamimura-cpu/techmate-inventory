# TechMate 在庫・古物台帳管理システム

個人事業「TechMate」(長野県上田市周辺の出張型スマホ・PC修理/中古端末の買取・販売)の業務で使うために作った、**古物台帳・在庫・資金繰りを1つにまとめた管理システム**です。

**▶ ブラウザで試す:https://kamimura-cpu.github.io/techmate-inventory/**
(ID `kamimura` / パスワード `demo1234` で管理者、ID `staff` / パスワード `demo1234` でメンバーとしてログインできます。データはすべて架空で、ブラウザの中にだけ保存されます)

## なぜ作ったか

2025年11月、輸出向けの取引が伸びたことで仕入れを一気に増やした結果、入金より先に支払日が重なり、約200万円あった運転資金が約20万円まで減りました。帳簿上は黒字でしたが、売上・在庫・支払日・口座残高がExcelやメモ、頭の中にバラバラにあり、「お金がいつ入り、いつ出ていくか」が見えていなかったことが原因でした。

そこで、**仕入れの前に「支払日の時点でお金がいくら残るか」を確かめられる**仕組みとして、このシステムを作りました。

## できること

| 機能 | 内容 |
| --- | --- |
| 古物台帳 | 古物営業法(第16条・第18条)と施行規則の記載事項・様式に沿って記録。訂正は上書きせず履歴を残す。印刷とCSV出力に対応 |
| 在庫管理 | 台帳に登録すると同じ番号で在庫が作られる。検品待ち→整備中→出品中→売約→入金済みを、ボタン1つで進められる |
| 資金繰り | 60日先までの残高の見込みをグラフで表示し、安全ラインを下回る日を警告。**仕入れ前チェック**で「その仕入れをしても大丈夫か」を判定 |
| 集計 | 月ごとの売上・原価・粗利、滞留在庫、販売先ごとの利益 |
| 権限 | メンバーは在庫の更新だけができ、お客様の個人情報やお金の情報は見えない(サーバー側でデータ自体を渡さない) |

## 構成

- `index.html`:サンプルデータ版(架空データ、ダブルクリックでも開ける)
- `google-apps-script/`:本番版。Google Apps Script のウェブアプリとして動き、データは管理者のGoogleスプレッドシートに保存。パスワードはソルト付きSHA-256で保存、書き込み時はロックで排他制御
- `src/`:共通部分。業務ルールは `src/logic.js` にまとめ、`python3 build.py` で両方の版を組み立てる
- [要件定義書.md](要件定義書.md):調べた法令・既存サービスと、そこから決めた仕様
- [本番版セットアップ手順.md](本番版セットアップ手順.md)
